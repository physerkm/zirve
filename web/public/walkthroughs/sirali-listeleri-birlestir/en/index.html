Merge Two Sorted Lists

Follow step by step how we use a dummy node (dummy) and a tail pointer (tail) to merge the nodes of two sorted linked lists into a single chain in ascending order.

The idea in three steps

  1. 1

    Start with a dummy node

    Instead of picking the first node of the result list with a special if, we put a placeholder dummy node in front; tail points to it at the start.

  2. 2

    Attach the smaller one to tail.next

    We compare the head values list1.val and list2.val, attach the smaller node to tail.next, and advance in that list.

  3. 3

    Append the remaining tail in one go

    When one list runs out, the remaining nodes of the other are already sorted; tail.next = list1 ?? list2 attaches them to the end in a single step.

Why is it so efficient?

No new nodes copied: O(1) extra memory

Apart from the single dummy node at the start, new ListNode() is never called. The next references of the existing nodes are simply redirected: O(1) space.

Single pass: O(n + m) time

At each step either list1 or list2 advances by one node. The total number of steps never exceeds the combined length of the two lists (n + m).

What does the dummy node buy you?

Without dummy, you would need a separate if-else and empty-list checks before the loop just to pick the first node. With dummy, every node is added the same way inside the same loop.

Why is the remainder attached without a loop?

In a linked list, attaching a node brings the entire chain behind it along. Since the remaining list is already sorted, a single tail.next = list1 ?? list2 assignment attaches all the remaining elements.
