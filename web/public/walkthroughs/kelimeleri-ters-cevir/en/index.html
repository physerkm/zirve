Reverse Words in a String

You can follow every step of the solution here. Pick a string, press Next or click Play, and see box by box what the three built-in methods in the solution, Split, Array.Reverse and string.Join, do under the hood.

The idea in three steps

  1. 1

    Cut at spaces, drop empty pieces

    Split(' ') cuts the string at every space. Two adjacent spaces, or leading and trailing spaces, leave empty pieces ("") behind; RemoveEmptyEntries drops them. Only the words remain.

  2. 2

    Reverse the array of words

    Array.Reverse swaps the first word with the last, the second with the second to last, and stops when they meet in the middle. It doesn't touch the letters inside the words.

  3. 3

    Join with a single space

    string.Join(" ", words) puts exactly one space between words and none at the start or end. That way the extra-space problem solves itself.

Why O(n) time and O(n) space?

O(n) time

Split reads the string once from start to end. Array.Reverse does m / 2 swaps for m words, and m can't exceed the string length. string.Join copies each letter into the result once. All three are proportional to the string length: O(n) time.

O(n) space

An array is created for the words, plus a new string for each word, and the result is a separate string too. Together they are as long as the input: O(n) space. Since strings are immutable in C#, the result has to be a new string anyway, so in C# this problem can't be solved with less than O(n) memory.

What if there were no RemoveEmptyEntries?

"a good example".Split(' ') gives ["a", "good", "", "", "example"]. After reversing and joining, the empty pieces act like words and extra spaces creep in: "example good a". Because RemoveEmptyEntries drops the empty pieces up front, this problem never arises.

Why doesn't Array.Reverse return anything?

Because it changes the array in place: it doesn't create a new array, it rearranges the words in words's own boxes. That's why its return type is void; a line like reversed = Array.Reverse(words) won't compile. Internally it works with two counters (i and j) starting from both ends, the same two-pointer idea as in Sort Colors.

How do you do it without built-in methods?

In interviews you are sometimes asked to solve it without Split. If you read the string from back to front, the words already come to you in reverse order: skip the spaces, mark the word's last letter, find its start and append it to the result. This approach also takes O(n) time and doesn't create a separate array of words.

StringBuilder sb = new StringBuilder();
int i = s.Length - 1;
while (i >= 0)
{
    while (i >= 0 && s[i] == ' ') i--;  // skip spaces
    if (i < 0) break;

    int end = i;                          // last letter of the word
    while (i >= 0 && s[i] != ' ') i--;  // go to the start of the word

    if (sb.Length > 0) sb.Append(' ');
    sb.Append(s, i + 1, end - i);         // append the word
}
return sb.ToString();

LeetCode's follow-up: reversing in place

If the string were a mutable character array, it could be done without extra memory. First reverse the whole string letter by letter: "eulb si yks eht". Then reverse each word within itself: "blue is sky the". Finally, remove the extra spaces by shifting left. Since string is immutable in C#, you first have to copy it into a char[], which already means O(n) memory. So in C# this follow-up doesn't make much sense.
