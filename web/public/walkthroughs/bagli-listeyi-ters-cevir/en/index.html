Reverse Linked List

You can follow every step of the solution here. Pick a list, press Next or click Play, and see how the arrows are flipped one by one and how the prev, current and next variables move forward.

The idea in three steps

  1. 1

    A linked list is a chain

    Each node holds a number (val) and an arrow (next) pointing at the next node. All you have is the first node (head). The last node's arrow points at null.

  2. 2

    Flip the arrows back one by one

    Walk the list from head to tail and point each node's arrow at the previous node. The first node's arrow turns to null, because once the list is reversed it becomes the last node.

  3. 3

    Save the path before flipping the arrow

    The moment you change current.next, the path to the rest of the list is cut. That's why you first save the next node with next = current.next.

Why O(1) space?

O(n) time

We visit each node once. The longer the list, the more steps it takes: O(n) time.

O(1) space

Whether the list has 5 nodes or 5000, we use only three variables (prev, current, next) and never create a new node: O(1) space.
