Walls and Gates

Instead of searching for a gate from every empty room, we spread the shortest distance to the empty rooms layer by layer with a multi-source BFS that starts from all gates at once.

The idea in three steps

  1. 1

    Put every gate in the queue

    At the start, add all 0 (gate) cells of the grid to the BFS queue at once. Together they form layer 0.

  2. 2

    Spread outward layer by layer

    Look at the four neighbors of every cell taken off the queue. Rooms 1 step away are discovered first, then rooms 2 steps away.

  3. 3

    The first to arrive is the shortest path

    The first wave to reach an empty room (INF) always comes from the nearest gate. Set its value to rooms[r][c] + 1 and add it to the queue.

Why is it so efficient?

Why start from the gates instead of the rooms?

Starting a separate BFS from every empty room takes O((m · n)²). When we put all gates in the same queue and run a single BFS, each cell is entered at most once and the time is O(m · n).

Is the first gate to arrive really the nearest?

Yes. The queue processes all gates at distance 0 first, then all rooms at distance 1, then those at 2. Whichever wave first touches an INF room got there in the fewest steps.

Why is no separate visited array needed?

Empty rooms start with the value INF. Because we set a room's value to rooms[r][c] + 1 as soon as we discover it, the rooms[nr][nc] != INF check automatically treats that room as visited.

What happens to unreachable rooms?

The BFS wave can never reach an empty room surrounded by walls (-1). So its value stays INF (2147483647), as the problem requires.
