Target Sum

Step through how we notice that the numbers with a + sign must add up to (sum + target) / 2, turn the problem into a subset counting problem, and fill in the table.

The idea in three steps

  1. 1

    Two equations

    P − N = target, P + N = sum. Adding them gives P = (sum + target) / 2.

  2. 2

    Rule out invalid cases

    If |target| > sum or sum + target is odd, there is no expression at all.

  3. 3

    Count subsets

    dp[t]: the number of subsets that sum to t. For each x, with t going down, dp[t] += dp[t − x].

Why does it work?

A one-to-one mapping

Each expression maps one-to-one to the set of numbers that get a +. So counting expressions is the same as counting subsets that sum to P.

Zeros

An element with value 0 does dp[t] += dp[t]: it doubles every subset (+0 and −0 are two different expressions).
