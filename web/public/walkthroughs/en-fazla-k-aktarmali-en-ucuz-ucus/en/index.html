Cheapest Flights Within K Stops

Step through how the Bellman-Ford algorithm uses a tempPrices copy in every round to find the cheapest costs reachable with at most k + 1 flights.

The idea in three steps

  1. 1

    Each round = 1 more flight

    Making at most k stops means using at most k + 1 flights. We run the outer loop exactly k + 1 times.

  2. 2

    Prevent chaining with a copy

    So that a city updated in a round cannot update another city in the same round, we read from prices and write to tempPrices.

  3. 3

    Relax the edges

    For each flight u → v (price), if prices[u] + price < tempPrices[v], we lower the destination city's cost.

Why is it so efficient?

Why do we use tempPrices?

If we updated the prices array directly, then right after 0 → 1 is updated in an iteration, the 1 → 2 flight would also use the new value. That would take 2 flights (1 stop) in a single round and break the k limit.

Time and Space Complexity

The algorithm runs k + 1 rounds in total and checks the E flights in constant time each round: O((k + 1) · E) time. It keeps only two arrays of n elements, so it uses O(n) space.
